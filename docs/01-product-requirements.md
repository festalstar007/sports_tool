# 第一版产品需求

## 1. 产品目标

用户每次跑步或步行结束后，可以上传运动应用详情截图，也可以在没有截图时快速手动录入。系统识别或计算主要运动指标，用户确认或修正后保存。用户可以在手机上查看历史记录以及按日、周、月变化的曲线。

正式访问地址为 `https://sports.345001.xyz`。

产品的第一价值是减少手工录入，同时保证数据可修改、可追溯。AI 识别仅作为录入助手，不作为不可修改的数据来源。

## 2. 目标用户与设备

- 单个用户本人。
- 主要设备为手机，竖屏操作。
- 通过浏览器访问，可添加到主屏幕作为 PWA。
- 默认时区为 `Asia/Shanghai`，界面语言为简体中文。

## 3. 支持的运动类型

| 截图标题 | 内部值 | 中文显示 |
| --- | --- | --- |
| 户外跑步 | `running` | 跑步 |
| 户外步行 | `walking` | 步行 |

如果无法确定类型，识别结果不得猜测为正式值，应要求用户手工选择跑步或步行。

## 4. 使用流程

1. 用户通过 Cloudflare Access 进入应用。
2. 首页点击“上传运动截图”。
3. 从手机相册选择一张 PNG、JPEG 或 WebP 图片。
4. 页面展示本地预览并开始上传、识别。
5. 识别完成后进入确认页面。
6. 用户检查运动类型、日期时间和全部指标。
7. 用户修改错误字段并保存。
8. 系统创建正式运动记录，并进入详情页。
9. 用户可在历史记录或趋势页面查看数据。

识别失败时，仍然进入确认页面，保留截图并允许用户手工填写。

没有截图时，用户可从首页进入“手动录入”，填写运动类型、时间、距离和时长；平均配速和平均速度由系统自动计算。平均心率、热量、步数和海拔数据均为选填。

## 5. 页面需求

### 5.1 首页 `/`

- 显示本周运动次数、总时长、总距离。
- 显示最近一次运动摘要。
- 提供明显的“上传运动截图”主按钮。
- 提供“没有截图？手动录入”入口。
- 提供历史记录和趋势分析入口。

### 5.2 上传与确认 `/imports/:id/review`

- 显示截图缩略图，可点击查看大图。
- 显示识别状态：上传中、识别中、待确认、识别失败。
- 表单字段见 `03-data-and-recognition.md`。
- 低置信度或交叉校验异常字段需要突出显示。
- 所有字段均允许用户编辑。
- 保存前校验必填字段和数值范围。
- 保存后不得因为重新识别而自动覆盖用户确认的数据。

### 5.3 手动录入 `/activities/new`

- 必填项仅为运动类型、运动时间、距离和时长。
- 时长使用小时、分钟、秒三个纯数字输入框，不要求用户切换键盘输入冒号。
- 平均心率在基础表单中作为重点选填字段。
- 热量、步数、累计爬升和累计下降放在折叠的“更多数据”区域。
- 平均配速、平均速度，以及有步数时的平均步频和步幅由程序自动计算并实时预览。
- 记住上一次手动录入选择的运动类型。

### 5.4 历史记录 `/activities`

- 按时间倒序展示。
- 可筛选全部、跑步、步行。
- 可选择日期范围。
- 列表项显示日期、类型、距离、时长、平均配速和平均心率。
- 支持进入详情页。

### 5.5 运动详情 `/activities/:id`

- 展示正式运动数据。
- 截图来源的记录展示已上传截图的 WebP 版本；手动记录不显示截图区域。
- 支持编辑和删除。
- 删除前二次确认。

### 5.6 趋势分析 `/trends`

- 时间范围：最近 7 天、30 天、90 天、全部。
- 运动筛选：全部、跑步、步行。
- 汇总指标：次数、总距离、总时长、总热量、总步数。
- 趋势指标：距离、时长、配速、速度、平均心率、步频、步幅、步数、热量和累计爬升。
- 距离、时长、步数和热量允许合并查看。
- 配速、速度、步频和步幅默认按运动类型分别查看。
- 配速图需要提示“数值越低表示越快”。

## 6. 图片约束

- 一次上传一张图片。
- 支持 `image/jpeg`、`image/png`、`image/webp`。
- 第一版最大文件大小建议 10 MiB。
- Worker 将上传图片转为 WebP，保持原始像素尺寸，用转换后的图片识别并存入 R2；不得导致正文文字难以识别。
- R2 Bucket 必须保持私有，图片通过受保护的 Worker API 获取。

## 7. 错误与恢复

- 上传失败：允许重试，不创建正式记录。
- 识别失败：保留导入记录和截图，允许手工填写。
- AI 返回非法 JSON：记录原始响应和错误，不直接保存为正式数据。
- 保存失败：保留表单输入并提示重试。
- 网络中断：不能重复创建同一条正式记录；创建接口使用导入 ID 保证幂等。

## 8. 隐私与安全

- 整个应用由 Cloudflare Access 保护。
- R2 图片不设公共访问域名。
- 日志不得输出截图二进制、完整 Access Token 或敏感请求头。
- API 必须确认请求经过 Access；本地开发允许通过明确的开发配置跳过。
- 提供删除记录和对应截图的能力。

## 9. 第一版成功标准

- 用户能在手机上用不超过一分钟完成一次截图导入和确认。
- 用户能在手机上用不超过三十秒完成一次基础手动记录。
- 两种样例截图均能正确提取所有可见字段。
- AI 失败时仍可手工完成记录。
- 跑步、步行可以分别筛选并查看曲线。
- 刷新页面或重新登录后数据仍然正确存在。
